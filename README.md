# Превью: пробная тренировка «Шагай Дома»

Статическое превью посадочной страницы «Попробуйте бесплатно шагательную тренировку для похудения». Это не боевой сайт: страница собрана для согласования, до переноса в Тильду.

- Оплата на странице идёт через официальные виджеты ГетКурса клуба walk-walk.ru. В репозитории нет секретов и токенов.
- Пробная тренировка встроена с YouTube (ролик «Мираж — Музыка нас связала [с Настей]», id `Zevc2_CBDnk`), в вертикальном формате 9:16.
